# 传播复盘：流量高，就代表传播有效吗？

> 本报告只分析题目提供的人工构造教学数据，不把模拟结果概括为真实平台规律。项目主要目标是取得合格预约，曝光是辅助观察指标。

## 一、指标计算

四条内容均使用发布后 `7×24小时` 的窗口。点击和曝光是次数；到页 UV 是本条内容来源内去重的访客数，未跨内容去重；合格预约按“首次完成合格预约时使用的内容链接”归因。

| 内容 | 链接点击率 | 页面转化率 | 每预约直接制作成本 |
| --- | ---: | ---: | ---: |
| A | `480÷8000×100%=6.00%` | `80÷400×100%=20.00%` | `80÷80=1.00元/人` |
| B | `600÷40000×100%=1.50%` | `50÷500×100%=10.00%` | `200÷50=4.00元/人` |
| C | `500÷10000×100%=5.00%` | `100÷400×100%=25.00%` | `150÷100=1.50元/人` |
| D | `480÷12000×100%=4.00%` | `100÷400×100%=25.00%` | `200÷100=2.00元/人` |

合计：曝光 `8000+40000+10000+12000=70000` 次；点击 `480+600+500+480=2060` 次；合格预约 `80+50+100+100=330` 人；直接制作费用 `80+200+150+200=630元`。

- 项目汇总点击率：`2060÷70000×100%=2.94%`。
- 每预约直接制作成本：`630÷330=1.91元/人`。
- 四行 UV 之和为 `400+500+400+400=1700`，`330÷1700×100%=19.41%` 只能叫“行汇总比”。由于 UV 没有跨内容去重，它不能被解释为项目在独立访客层面的真实页面转化率。
- 本题各项分母均不为零，没有“不适用”的指标。

## 二、数据主张判断

1. **说法1不成立。** B 的曝光最高，说明它在四条内容中获得了最多展示；但项目目标是合格预约，B 只有50人预约、页面转化率10.00%、每预约成本4.00元，不能称为最有效。更准确的表述是：B触达规模最大，但预约效率较低。
2. **说法2不成立。** 四条内容的分母不同，`(6.00%+1.50%+5.00%+4.00%)÷4=4.13%`只是四条内容比率的非加权平均。项目汇总点击率应先合计点击和曝光，再计算，结果为2.94%。
3. **说法3不成立。** `330÷1700=19.41%`是把各行记录相加后的比值，不是独立访客转化率。同一访客可能出现在多个 UV 行，分母会重复；要回答项目层面的独立访客转化率，必须获得跨内容去重的项目 UV及相匹配的预约口径。
4. **说法4不成立。** C 的页面转化率高于B是自然分发数据中的描述性差异，不能证明“图文”导致更高转化。两行同时改变了形式、主题、受众、发布时间等条件，存在混杂因素。

可能影响比较的因素至少包括内容主题、受众构成、发布时间和账号既有触达；现有数据还不能回答独立总受众、到场或课程完成、满意度、阅读完成度、完整成本及差异的统计不确定性。

## 三、实验解读与后续设计

### 1. 按钮文案实验

| 组别 | 预约转化率 | 与E相比的绝对差异 | 与E相比的相对变化 |
| --- | ---: | ---: | ---: |
| E：立即预约 | `96÷1200×100%=8.00%` | 基准 | 基准 |
| F：查看安排并预约 | `120÷1200×100%=10.00%` | `10.00%-8.00%=2.00`个百分点 | `(10.00%-8.00%)÷8.00%=25.00%` |

在这次随机分组、其余页面内容一致、观察7天的模拟实验中，F 组样本预约率高于 E 组，观察差异为2个百分点，约为E组的1.25倍。由于题目没有提供置信区间、统计检验或实施质量检查，不能仅凭两个比例断言 F 文案对所有人、所有页面或所有时期普遍更有效。还应评估随机分组是否执行无误、样本是否有异常或缺失，并报告统计不确定性；结论首先适用于本实验定义的符合条件访客和7天窗口。

### 2. A/B测试方案

材料一中 A 与 C 的结果提示“内容顺序可能影响预约”，但它们同时存在主题差异，不能直接拿两行数据做因果结论。下面设计一次只改变首屏顺序的测试。

| 设计要素 | 方案 |
| --- | --- |
| 假设 | 对同一批符合条件的潜在报名者，在其他条件相同的情况下，首屏先展示“作品示例与课程内容”比先展示“参与规则”能带来更高的合格预约率。 |
| 唯一主要改动 | 制作两版同尺寸、同主题、同文案长度和同一预约入口的图文卡，只交换首屏两个信息区块的顺序；不直接把现有C、A整行当作实验组和对照组。 |
| 分组 | 以首次接触内容的稳定账号或匿名访客ID为随机单位，1:1随机分配；同一ID始终看到同一版本，禁止同一人跨组点击两个入口。 |
| 主要指标 | `7天内首次合格预约人数÷首次接触该版本的符合条件去重访客人数×100%`。分子和分母都按组记录，选择它是因为项目主要目标是合格预约。 |
| 观察与结束条件 | 每位访客从首次接触起观察7天；计划两组各至少1000名完整观察访客，达到后停止招募并完成随访。若14天仍未达到，报告样本不足；机器人、重复ID和技术故障按事先写好的规则处理，两组一致执行。 |
| 结论限制 | 报告两组比例、绝对差、相对变化及置信区间或统计检验，不因中途看到好结果而提前结束。结论只适用于本次受众、内容位置、时间和页面，不能自动推广到其他主题或平台。 |

## 四、给团队的行动建议

1. **优先优化预约效率。** C、D各带来100名合格预约，C的直接成本为1.50元/人；先把“作品示例/课程内容”和“参与流程”拆成只改一个变量的A/B版本，比较7天合格预约率与成本。还缺跨内容独立UV和统计不确定性。
2. **把B当作触达素材而非成功标准。** B有最高曝光却只有1.50%点击率、10.00%页面转化率和4.00元/人；应测试更清楚的行动入口，并记录汇总点击率、预约率和后续到场。还缺阅读完成、到场和完整成本数据。

## 五、核验与AI使用说明

### 已完成的核验

1. 逐行复算 C：`500÷10000=5.00%`、`100÷400=25.00%`、`150÷100=1.50元/人`，与表格一致。
2. 复算合计：曝光 `70000`、点击 `2060`、预约 `330`、费用 `630`；汇总点击率为 `2.94%`，每预约直接成本为 `1.91元/人`。
3. 检查去重范围：确认题目只对每行 UV 去重，未对跨行 UV 去重，因此将 `330÷1700=19.41%`标为行汇总比，没有写成真实独立访客转化率。
4. 复算按钮实验：E 为 `8.00%`，F 为 `10.00%`，绝对差为 `2.00`个百分点，相对变化为 `25.00%`，没有把百分点写成百分比。
5. 检查四条内容的观察窗口均为发布后 `7×24小时`，并确认没有零分母、付费流量或实际传播结果可供虚构。

### AI协作披露

本成果使用当前 Codex 作为生成式AI辅助，参与位置包括结构整理、公式复核、数据主张的边界表述和A/B测试方案草拟。输入仅限本题材料与课程资料，没有输入个人信息或外部保密资料。所有数据均由题目提供，计算由人工按公式逐项复算，最终文字由人工对照题目口径审定。

一处具体修订记录：

- 草稿表述：**“C比B的页面转化率高，说明图文形式会带来更高转化。”**
- 人工核验后：**“C比B高是自然分发数据中的描述性差异；形式、主题、受众和发布时间同时变化，不能推出图文的因果效果。”**

修订依据是题目说明四条内容未随机分组且主题、受众构成和发布时间不同；因此没有把AI草稿中的因果化表述保留。报告未编造实验结果、到场结果、用户评价或平台规律。
