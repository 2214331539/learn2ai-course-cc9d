# 《新媒体传播》课程大纲

## 一、课程定位

新媒体传播研究数字技术、平台机制、社会关系与内容表达如何共同影响信息生产、流通和理解。本课程以日常可观察的传播现象为起点，训练学生提出问题、收集证据、设计内容并评估结果。

适用对象：本科或高职初学者、跨专业学习者。先修要求：基本阅读写作能力和常见数字工具操作能力；不要求编程或付费软件。

建议学时：16周×每周2课时，共32课时；每课时45分钟。建议每周课外投入1—2小时，用于阅读、观察与作品修改。

## 二、学习目标

完成课程后，学生能够：

| 编号 | 可观察的学习成果 | 主要证据 |
| --- | --- | --- |
| O1 | 使用传播模型及至少两种理论解释同一传播现象，并说明解释的局限 | 平台观察、案例分析 |
| O2 | 通过资料、访谈或观察提出受众需求判断，区分证据和假设 | 受众研究备忘录 |
| O3 | 围绕受众任务制作表达清楚、来源可追溯的图文或视频原型 | 内容脚本、原型、来源表 |
| O4 | 形成目标、内容、渠道、行动入口和评估指标一致的传播方案 | 传播简报、触点图、排期 |
| O5 | 正确计算常用指标，解释数据限制，区分相关关系与因果关系 | 数据分析、实验草案 |
| O6 | 识别隐私、版权、误导与AI使用风险，并展示核验和修订过程 | 核验表、AI记录、项目复盘 |

## 三、教学内容

1. 新媒体与传播基础：传播链条、议程设置、使用与满足、创新扩散、参与式文化。
2. 平台机制与算法：媒介可供性、分发方式、商业目标、用户选择与内容可见性。
3. 受众与社群：需求、访谈、受众细分、社群治理、参与和沉默。
4. 内容与叙事：信息结构、故事表达、图文与短视频、无障碍与事实核验。
5. 传播策划：目标与受众、渠道协同、行动路径、排期和资源。
6. 效果评估：指标口径、漏斗、描述性比较、A/B测试和归因边界。
7. 伦理与风险：隐私、版权、失实信息、商业透明度、回应和纠错。
8. AI与综合实践：协作分工、核验责任、过程记录、项目展示和复盘。

## 四、教学组织

每周90分钟可采用“概念讲解20分钟—材料分析20分钟—小组实践35分钟—交流与退出条15分钟”的结构。具体活动可按课堂人数调整。

建议3—5人组成项目组，围绕校园服务、公共科普或文化传播形成一项学期项目。各组选择能获得资料、能核验事实且无需高成本投放的主题。班级较小时可个人完成。

实践过程依次形成：平台观察 → 受众研究 → 内容原型 → 传播方案 → 数据解释 → 风险修订 → 最终展示。每个学生应能说明自己的贡献和关键判断。

## 五、建议考核结构

| 项目 | 比例 | 评价依据 |
| --- | --- | --- |
| 课堂参与与学习记录 | 15% | 课前准备、讨论质量、反思和同伴反馈；不按发言次数机械计分 |
| 模块练习与作品集 | 35% | 平台观察10%、受众研究10%、内容原型10%、数据练习5% |
| 学期综合项目 | 50% | 项目成果40%、个人答辩与反思10% |
| 合计 | 100% | 细则见《评价量规》 |

这是可调整的课程设计方案。正式考核以任课教师公布的课程要求为准；阅读量、粉丝量和是否“爆款”均不直接等同于成绩。

## 六、AI协作与学术规范

AI可用于构思、结构整理、语言修改和数据分析辅助。学生须说明使用位置、保留关键输入输出及人工修改，并对最终内容负责。不得编造访谈、引用、数据或核验记录，不得把AI生成内容冒充真实采访或实拍。

对外发布、采访录音和个人信息收集应遵循适用规则及学校要求；课程练习默认可用纸面方案或离线原型完成。需要真实发布时，由教师另行明确范围和流程。

## 七、教学资源与适配

材料优先选择可公开访问的原始来源。教师可用板书、文档、幻灯片和免费编辑工具开展教学，无须学生注册特定付费平台。

若压缩为8周，可将相邻两周合为一周，但仍保留受众研究、内容原型、数据分析和伦理复核四个实践环节；若扩展为48课时，可增加访谈、制作和项目反馈时间。
