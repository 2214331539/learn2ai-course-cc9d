# 新媒体传播 · 课程资料导航

本资料包面向初学者，将传播理论与平台观察、内容制作、效果评估连接起来。建议用于本科或高职入门课程；默认 **16周、32课时，每课时45分钟**，可按实际教学安排调整。

资料建立日期：2026年10月11日。当前为课程起始版本；学时、考核比例和课堂任务均为教学建议，须由任课教师结合学校要求确定。

## 使用说明

1. 教师可先查看大纲和教学进度，再选择对应讲义与活动；每两周完成一个模块。
2. 学生每周阅读对应讲义，保留观察、资料来源、修改记录和结论依据，逐步形成课程作品集。
3. 本资料中的案例、账号和数据如标为“虚构”或“模拟”，仅用于教学，不代表真实平台表现。
4. 涉及平台规则、产品功能、法律适用和热点事件时，应补充授课当期可核验的资料；本资料不声称已经核验实时规则。
5. 活动和项目模板用于课堂教学。正式作业的题目、期限、提交要求，以课程中单独发布的作业为准。
