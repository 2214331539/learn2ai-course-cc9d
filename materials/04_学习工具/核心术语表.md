# 核心术语表

术语用于帮助提出和检查问题。涉及平台数据时，以实际数据字典为准，不把这里的教学口径自动套用到所有平台。

## 一、传播与平台

| 术语 | 简明解释 | 使用提醒 |
| --- | --- | --- |
| 新媒体 | 特定时期中由数字化、网络化等条件塑造的媒介形态与传播关系 | 不是固定不变的应用名单 |
| 传播效果 | 传播后在知晓、理解、态度、行动等方面可观察的变化 | 不同层次需要不同证据 |
| 把关 | 信息被选择、组织、过滤和呈现的过程 | 平台、机构、用户等都可能参与 |
| 议程设置 | 媒体议题显著性与公众议题显著性之间的关系 | 不等于媒体能直接决定所有人的意见 |
| 使用与满足 | 从使用者的需要和选择理解媒介使用 | 还应考虑结构条件与报告偏差 |
| 创新扩散 | 创新通过渠道，在时间中于社会系统内传播的过程 | 采用模式取决于具体情境 |
| 参与式文化 | 用户在创作、协作和流通中的参与实践 | 不代表所有人参与机会平等 |
| 媒介可供性 | 技术与使用者之间形成的行动可能 | 同一功能可能有多种用法 |
| 平台化 | 平台的基础设施、规则和商业逻辑进入社会活动的过程 | 不只涉及技术接口 |
| 推荐系统 | 从候选内容中选择和排序，向使用者呈现内容的系统 | 外部观察通常不知道内部全部规则 |
| 信息茧房 | 对信息接触趋于封闭或同质化的概括性说法 | 应作为待研究问题，不能仅凭印象认定 |

## 二、受众与策划

| 术语 | 简明解释 | 使用提醒 |
| --- | --- | --- |
| 受众细分 | 按需求、行为、情境等区分具有行动意义的群体 | 不只按年龄和性别贴标签 |
| 受众洞察 | 有材料支持的任务、障碍与动机理解 | 与未经验证的画像区分 |
| 社群 | 围绕共同关注形成持续互动及一定规范的群体 | 群人数不直接代表关系质量 |
| 用户生成内容（UGC） | 用户创作或发布的内容 | 内容仍涉及事实、版权和隐私责任 |
| 行动入口 | 引导受众完成下一步的明确方式 | 如预约、查询、求助；要能实际使用 |
| 触点 | 受众与信息、服务或组织接触的具体位置或情境 | 可包括线上页面和线下场景 |
| 传播漏斗 | 将触达至目标行为的步骤拆分观察的方法 | 检查各步骤的单位和去重范围 |
| 跨平台协同 | 不同平台围绕同一目标承担互补职责 | 不等于逐字重复发布 |

## 三、数据与研究

| 术语 | 简明解释 | 使用提醒 |
| --- | --- | --- |
| 曝光 | 按数据源规则记录的展示次数 | 不等于实际阅读或人数 |
| 触达 | 在指定范围内去重的接触人数 | 要注明去重窗口，跨内容可能重复 |
| UV | 在指定窗口与范围内去重的访客数 | 不同设备和平台的识别规则可能不同 |
| 点击率（CTR） | 本课程例：链接点击次数÷曝光次数 | 先明确是哪一种点击和曝光 |
| 转化率 | 目标行为量÷相应基数 | 必须同时说明行为、分母、单位和窗口 |
| 归因 | 按一定规则把结果分配给渠道或触点 | 归因规则不自动证明因果关系 |
| 便利抽样 | 从容易接触的对象中选择样本 | 结果通常不能直接代表总体 |
| 混杂因素 | 同时关联比较条件与结果、可能影响解释的因素 | 如内容主题、受众和发布时间 |
| A/B测试 | 将对象分配到不同条件进行比较的实验方法 | 随机分配、主要指标和结束规则很关键 |
| 百分点 | 两个百分率的绝对差 | 10%到12%增加2个百分点，相对增加20% |
| 统计不确定性 | 有限样本和随机变化带来的估计不确定 | 不能只凭观察差异断言普遍有效 |

## 四、伦理与AI

| 术语 | 简明解释 | 使用提醒 |
| --- | --- | --- |
| 知情同意 | 在了解相关用途等信息后自愿作出同意 | 不等于无限范围、无限期限授权 |
| 去标识化 | 处理直接标识信息以减少身份关联 | 仍可能存在再识别风险 |
| 事实核验 | 通过可追溯证据检查事实主张 | 搜索摘要和AI回答不能替代原始来源 |
| 生成式AI | 能基于输入生成文本、图像等内容的模型或系统 | 内容可能出错，须人工核验 |
| AI幻觉 | AI生成看似可信但不真实或缺乏依据的内容 | 包括虚构引用、人物和计算结论 |
| AI使用披露 | 说明AI参与位置、采用内容和人工处理 | 披露不替代事实、版权和隐私责任 |
