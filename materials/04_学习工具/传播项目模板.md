# 传播项目模板

以下模板可复制用于课堂练习。填写时用“待核验”“未知”“不适用”区分信息状态，避免为完整而编造内容。正式作业以另行发布的题目为准。

## 模板1：一页传播简报

| 项目 | 填写内容 |
| --- | --- |
| 项目名称、成员、日期、版本 |  |
| 要解决的传播问题 | 描述现状、影响及依据 |
| 受众与使用情境 | 谁在何时何地需要完成什么任务 |
| 受众障碍和证据 | 资料、观察或访谈支持；注明样本局限 |
| 目标与时间窗口 | 具体变化、目标值、基线或设值理由 |
| 核心信息 | 一句话说明价值，附事实依据 |
| 内容与渠道职责 | 触达、解释、答疑、行动分别由谁承担 |
| 行动入口 | 受众下一步怎么做，失败时怎么办 |
| 资源与分工 | 时间、人力、工具、预算、主要负责人 |
| 评估方法 | 指标、分子分母、来源、记录时间 |
| 风险与备用方案 | 隐私、版权、失实信息、入口故障等 |
| 待验证假设 | 目前哪些判断尚未得到证实 |

## 模板3：受众访谈与洞察

知情说明示例：“我们正在做课程研究，想了解你处理闲置教材的经历，预计5—10分钟。参与自愿，可以跳过问题或随时结束。默认只做匿名文字记录，材料用于课堂分析；未经另外同意不录音、不公开个人身份。”应据实际用途补充保管、访问和删除安排。

访谈编号：____；日期：____；是否同意：____；记录方式：____；保管人及删除安排：____。

建议问题：

1. 请讲讲你最近一次处理闲置教材的过程。
2. 哪一步最困难？能举一个具体例子吗？
3. 你从哪里获得信息？为什么使用这个渠道？
4. 有没有放弃或改用其他方式？当时发生了什么？
5. 如果再次处理，你最需要哪条信息或哪项支持？

| 匿名原话或观察 | 主题标签 | 洞察假设 | 反例/局限 | 可测试的设计建议 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

不要将整理后的概括加引号冒充原话，也不要把AI补写的内容作为访谈记录。

## 模板7：项目复盘与个人贡献

| 问题 | 记录 |
| --- | --- |
| 最初目标与实际产出是什么？ | 区分真实效果、模拟结果和未发布原型 |
| 哪项选择最有依据？ | 指向资料、访谈、测试或计算 |
| 哪个判断发生了变化？为什么？ | 保留修改前后版本和触发依据 |
| 哪些假设仍未验证？ | 说明材料、时间或方法限制 |
| AI在哪些位置参与？ | 采用、修改、舍弃及核验方式 |
| 每位成员具体贡献是什么？ | 任务、产物及可检查记录 |
| 下一次优先改进什么？ | 写明行动、负责人、时间和评估办法 |

最终展示建议：问题与受众 → 证据 → 内容与路径 → 评估 → 风险 → 修改与反思。
