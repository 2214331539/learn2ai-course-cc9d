# 事实核验与AI使用清单

适用于课堂原型、项目方案和计划对外发布的内容。根据任务选择适用项，不能核实的内容列为待确认，不用打勾代替证据。

## 一、事实和来源

- [ ] 将可核验的事实、个人意见、推测和虚构情境分开标记。
- [ ] 姓名、时间、地点、金额、规则、引用和数据已回到原始材料核对。
- [ ] 检查材料的发布日期、适用范围和版本；没有把旧规则写成当前规则。
- [ ] 重要主张尽可能由独立来源交叉核对；来源之间是否互相转引已说明。
- [ ] 引语与原文一致，转述未改变原意；没有用搜索摘要代替完整内容。
- [ ] 图像、视频和截图已核对上下文；生成或重构内容未冒充实拍或采访。
- [ ] 无法核实或存在争议的信息已删除、注明不确定性或等待进一步确认。

## 二、素材、隐私和可访问性

- [ ] 图片、音乐、字体、引文及其他素材的作者、许可和必要署名已登记。
- [ ] 没有把“能下载”或“标明出处”当作自动获得使用许可。
- [ ] 采访、录音、肖像和聊天截图的实际用途与授权范围一致。
- [ ] 仅保留任务所需个人信息，访问范围、保管责任和删除安排明确。
- [ ] 对可能暴露身份的组合信息也进行了检查。
- [ ] 字幕、文本说明、对比度、链接文字及关键信息不依赖单一颜色等方面已检查。
- [ ] 商业关系及可能引起来源误认的合成内容按适用要求作了标识。

- [ ] 未把不允许外传的资料或不必要的个人信息输入外部AI服务。
- [ ] 引用和来源已独立打开核对，计算已复算关键数值。
- [ ] 未编造真实访谈、实验、发布记录、用户评价或传播效果。
- [ ] 清楚标注教学模拟、生成图像、合成音频等内容的性质。
- [ ] 披露AI参与的具体位置，说明人工承担的工作和最终审定责任。
- [ ] 保留关键版本和修改依据，不要求为记录而保存无关私人信息。

披露示例：“AI辅助生成通知结构和修改语言。时间、地点、规则由团队对照组织方材料核验；删除了AI补写的一条未经证实的效果描述。文案与来源表经人工审定。”未使用AI时可写“本项成果未使用生成式AI”。

## 四、数据与结论

- [ ] 指标注明分子、分母、单位、窗口和去重范围。
- [ ] 缺失、异常和零分母已按规则处理。
- [ ] 没有把行为次数写成人数，没有把未跨行去重的UV相加当独立总人数。
- [ ] 说明样本范围、混杂因素和不能回答的问题。
- [ ] 观察性比较未被直接写成因果效果；实验未仅凭比例差异断言有效。
- [ ] 真实结果、模拟计算和计划目标明确区分。

## 五、发布或展示前

- [ ] 标题、正文、图像、规则和入口一致，链接可用。
- [ ] 对外发布所需的组织审核、权限和流程已确认。
- [ ] 重要信息变更、评论答疑和纠错负责人明确。
- [ ] 成果版本、核验日期和待确认事项可找到。

课堂原型可以保持离线。实际发布前须按当期法律、平台及学校规则再检查；本清单不是法律结论或发布授权。
